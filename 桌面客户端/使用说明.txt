校园车辆出入登记管理系统 · 桌面客户端使用说明
=====================================================

一、两个安装包的区别

  校园车辆出入登记管理系统-便携版-1.0.0.exe
    免安装，双击直接用。适合拷到 U 盘、临时在别的电脑上演示。
    首次运行会在临时目录解压，启动比安装版慢 2~5 秒。

  校园车辆出入登记管理系统-安装版-1.0.0.exe
    正常安装，可自选安装目录，装完自动创建桌面和开始菜单快捷方式
    （不想要桌面图标的话，装完直接删掉桌面那个快捷方式即可）。
    推荐日常使用，启动更快，卸载走「设置 → 应用」。

  两个包功能完全一样，只是打包形式不同，选一个即可。


二、使用步骤

  1. 先启动服务端
     双击项目根目录的「启动系统.bat」，等窗口出现
     Started CampusVehicleApplication 字样（首次启动会自动建表）。

  2. 再双击桌面客户端
     系统会自动连上 http://127.0.0.1:8080 并打开登录页。

  3. 如果先开了客户端、后开服务端
     客户端会显示「后端服务暂未启动」，启动服务端后 3 秒内自动进入，不用关窗口。

  说明：exe 只是界面（原来的网页），数据仍然全部存在 MySQL 里，
       关掉客户端不会丢数据；导出、扫码、审核等逻辑都在后端。


三、后端不在本机怎么办

  默认连本机 8080 端口。如果服务端跑在云服务器（例如 192.144.235.177:8088），
  修改配置文件：

      C:\Users\你的用户名\AppData\Roaming\campus-vehicle-desktop\config.json

  把 server 改成对应地址，例如：

      { "server": "http://192.144.235.177:8088" }

  改完重启客户端即可。也可以用命令行临时指定：
      CampusVehicle.exe --server=http://192.144.235.177:8088


四、几个细节

  · 门岗扫码：客户端已放开摄像头权限，首次扫码若系统弹窗询问，选「允许」。
  · 导出 Excel：文件默认存到「下载」文件夹，完成后会弹窗提示，可直接打开所在文件夹。
  · 快捷键：F12 或 Ctrl+Shift+I 打开开发者工具，Ctrl+R / F5 刷新页面。
  · 密码、登录态：与网页版一样，关闭后会保持登录，令牌 12 小时过期需重新登录。


五、想改界面或重新打包

  前端源码目录 frontend\src 目前不在项目里（只有构建好的 frontend\dist），
  因此现在打包是基于已有 dist 做的。把 src 放回 frontend\ 下之后：

     双击项目根目录的「打包桌面客户端.bat」

  脚本会自动 build 前端 → 同步到 desktop\app-dist → 生成新的 exe，
  产物在 desktop\release\ 。桌面端源码在 desktop\electron\（main.js / server.js）。
